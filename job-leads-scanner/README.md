# סורק לידים ממודעות דרושים ומכרזים

הכלי סורק שני סוגי מקורות: **מודעות דרושים** של קמפיינרים ואנשי שיווק דיגיטלי, ו**מכרזים פתוחים** לשירותי פרסום, דיגיטל ואתרים. כל ליד רלוונטי נכנס ל**בורד במאנדיי**, עם איש קשר, קישורים וטיוטת פנייה.

על מודעות הדרושים: הוא מזהה מי מהמפרסמים הוא **עסק שמגייס לעצמו** (ליד) ומי הוא **סוכנות** (מתחרה), ומכין לכל ליד טיוטת מייל עם הצעה לצוות מלא במיקור חוץ: קמפיינר, עיצוב, דפי נחיתה ותוכן.

## איך מריצים

```bash
cd job-leads-scanner
npm install
npm run scan            # סריקה, סיווג ודוח
```

בסיום נוצרים:
- `report.html`: הדוח. פותחים אותו בדפדפן.
- `data/leads.csv`: הלידים בקובץ CSV, לייבוא ל-monday או לאקסל.
- `data/leads.json`: המאגר המלא. סריקה חוזרת מוסיפה רק מודעות חדשות.

### אפשרויות

| פקודה | מה היא עושה |
|---|---|
| `node src/scan.js --no-ai` | סיווג לפי חוקים בלבד, בלי Claude |
| `node src/scan.js --keywords "קמפיינר,PPC"` | חיפוש במילים אחרות |
| `node src/scan.js --add examples/manual-ads.json` | הוספה ידנית של מודעות מלינקדאין, מפייסבוק וכו' |
| `node src/scan.js --reclassify` | סיווג מחדש של כל המאגר |
| `node src/scan.js --report-only` | בניית הדוח מחדש בלי לסרוק |

## מכרזים

**מקור 1: mr.gov.il (מינהל הרכש הממשלתי).** הכלי מחפש לפי מילים כמו "קמפיין", "שירותי פרסום", "דיגיטל", "רשתות חברתיות" ו"אתר אינטרנט", ונכנס לעמוד של כל מכרז רלוונטי. מהעמוד הוא לוקח את **שם איש הקשר והמייל שלו**, את המועד האחרון להגשה ואת הקישור למערכת ההגשה.

- **נכנסים:** מכרז פומבי, RFI, בקשה לקבלת מידע, קול קורא, וגם כוונה להתקשרות (שעדיין אפשר להגיש עליה התנגדות).
- **מסוננים החוצה:** פטורים, הארכות התקשרות, מכרזים שהמועד שלהם חלף, ונושאים שאינם שלנו (רישוי, ציוד, ניטור וכו').
- **ציון:** גבוה יותר להליך פתוח לכל ספק, לנושא שהוא ליבת השירות שלנו, ולזמן נוח עד ההגשה.

**מקור 2: עמודי מכרזים של גופים ספציפיים.** עיריות, חברות ממשלתיות, אוניברסיטאות ותאגידים מפרסמים מכרזים באתרים שלהם, ולא ב-mr.gov.il. מוסיפים ב-`config.local.json` את כתובות העמודים שרוצים לעקוב אחריהם:

```json
{ "tenderPages": [ { "name": "עיריית תל אביב", "url": "https://..." } ] }
```

הכלי סורק את הקישורים בכל עמוד, ומוסיף כל מכרז שהכותרת שלו בתחום שלנו. אין אתר חינמי שמרכז את כל המכרזים בישראל. יפעת מכרזים עושה את זה, אבל בתשלום.

## סנכרון למאנדיי

הבורד **🎯 לידים ממודעות דרושים ומכרזים** נמצא ב-Sales CRM, בתיקייה "לידים". יש בו שלוש קבוצות: מכרזים פתוחים, משרות (לידים חמים), ומשרות (לידים נוספים). כל ליד משויך למעוז ומקבל סטטוס "חדש".

**העמודות בבורד:** סטטוס טיפול, איש מכירות, סוג ליד, ציון, חברה או מפרסם, המעסיק האמיתי, איש קשר, מייל, מועד אחרון להגשה, קישור למודעה או למכרז, חיפוש איש קשר (או הגשה, במכרזים), תעשייה, עיר, צרכים נוספים, תאריך פרסום, למה זה ליד, נושא מייל וטיוטת מייל.

כדי שכל סריקה תוסיף לידים חדשים לבורד, מגדירים טוקן:

```bash
export MONDAY_API_TOKEN=...   # במאנדיי: תמונת הפרופיל, אחר כך Developers ואז My access tokens
npm run scan
```

- **כפילויות:** כל ליד נוצר פעם אחת בלבד. הכלי בודק לפי העמודה "מזהה ליד", גם אם הקובץ `data/leads.json` נמחק.
- **שינויים בבורד:** הכלי לא דורס סטטוסים או הערות שמעוז עדכן בבורד.
- **סף:** נכנסים רק לידים עם ציון 45 ומעלה (`monday.minScore`). סוכנויות ומשרות לא רלוונטיות לא נכנסים לבורד.

## איך הסיווג עובד

לכל מודעה נקבעים שלושה צירים:

| ציר | ערכים | איך מזהים |
|---|---|---|
| **מי פרסם** | חברה ישירה / חברת השמה / חסוי | שם המפרסם, וביטויים כמו "לאחד מלקוחותינו" או "לחברה מובילה" |
| **מי המעסיק** | עסק / סוכנות | "משרד פרסום", "תיקי לקוחות", "לקוחות מתחומים שונים" מצביעים על סוכנות. "מול משרד הפרסום" ו"לצד הלקוח" מצביעים על עסק |
| **רלוונטיות** | כן / לא | האם זה תפקיד קמפיינים או דיגיטל שאפשר להחליף בשירות |

**ציון ליד (0-100):** גבוה לעסקים קטנים ובינוניים שמגייסים תפקיד ביצועי, במיוחד כשהמודעה מבקשת גם דפי נחיתה, עיצוב או תוכן. נמוך לאוניברסיטאות, לבתי חולים, לתאגידים ולתפקידים בכירים. סוכנויות מקבלות 0.

**חברה שזוהתה כסוכנות במודעה אחת שלה מסווגת כסוכנות גם בכל המודעות האחרות שלה.**

### סיווג חכם עם Claude (אופציונלי)

אם מוגדר `ANTHROPIC_API_KEY`, כל מודעה רלוונטית נשלחת ל-Claude. Claude מחזיר ניחוש מדויק יותר של המעסיק האמיתי, וגם **זווית פנייה** מותאמת שנכנסת למייל. בלי מפתח הכלי עובד עם חוקים בלבד.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
npm run scan
```

ההגדרות: מודל `claude-opus-5-5` ברמת מאמץ `low`. בנוסף מופעל `fallbacks: "default"`: אם Claude מסרב לבקשה, היא עוברת אוטומטית למודל חלופי. אפשר לשנות את זה ב-`config.local.json`.

## לפני ששולחים מיילים: חוק הספאם

לפי **סעיף 30א לחוק התקשורת** מותר לפנות **לבית עסק פעם אחת** בבקשה לקבל הסכמה לדיוור. לכן:
- טיוטת המייל מנוסחת כפנייה אישית אחת, שמבקשת רשות לשלוח הצעה וכוללת אפשרות להסיר.
- **שולחים ידנית, אחד אחד.** הכלי לא שולח מיילים בעצמו.
- מי שלא ענה לא מקבל מייל נוסף.

## מקורות

- **Drushim:** נסרק העמוד הציבורי של תוצאות החיפוש, עמוד אחד לכל מילת חיפוש (כ-25 מודעות), עם השהיה בין הבקשות.

- **לינקדאין:** תנאי השימוש שלו אוסרים סריקה. מוסיפים ממנו מודעות ידנית עם `--add`.
