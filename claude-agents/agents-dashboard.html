חדר הסוכנים

כל הסוכנים שזמינים לך ב־Claude Code: ארבעת סוכני השיווק שבנינו מהמדריך של אימפרוב, והסוכנים שמגיעים מובנים. לחצו על "הכללים והבדיקות" כדי לראות איך כל סוכן מחליט.

סוכני השיווק קבצים ב־~/.claude/agents

סוכנים מובנים מגיעים עם Claude Code, בלי התקנה

אין סוכן שמתאים לחיפוש.

התקנת סוכני השיווק

  1. מעתיקים את ארבעת הקבצים מהתיקייה claude-agents/agents אל ~/.claude/agents/ (ב־Windows: C:\Users\<שם>\.claude\agents\).
  2. פותחים מחדש את Claude Code ומקלידים /agents.
  3. ממלאים בכל קובץ את מה שבסוגריים המרובעים: העסק, מה נחשב פנייה, המחיר לפנייה.
מקור הכללים: "מה סוכנים באמת יודעים לעשות בסושיאל ובממומן", שלהבת ורדי, אימפרוב.
