# 4 סוכני שיווק ל-Claude Code

מבוססים על המדריך "מה סוכנים באמת יודעים לעשות בסושיאל ובממומן" (אימפרוב).

| קובץ | סוכן | מה הוא עושה |
|---|---|---|
| `agents/social-content-planner.md` | נועה | מתכנן וכותב פוסטים שמביאים פניות, ועוקב אחרי מילות פנייה |
| `agents/video-editor.md` | ליאור | בוחר צילומים לפי תסריט ותמלול SRT, וזוכר מה נפסל |
| `agents/meta-ads-manager.md` | סוכן הממומנים של נועם | מחליט מה לעשות עם כל מודעה במטא, כותב מודעות, ומפיק דוח שבועי |
| `agents/competitor-researcher.md` | כָּלֵב | מפרק עמודי מתחרים ומראיין אותך כדי לנסח את הקול שלך |

## התקנה במחשב

1. העתיקו את ארבעת הקבצים שבתיקייה `agents` אל:
   - **Mac / Linux:** `~/.claude/agents/`
   - **Windows:** `C:\Users\<שם המשתמש>\.claude\agents\`

   (אם התיקייה לא קיימת, צרו אותה.)
2. פתחו מחדש את Claude Code. הקלידו `/agents` כדי לראות שהם מופיעים.
3. פתחו כל קובץ ומלאו את מה שבסוגריים המרובעים (העסק, המחיר לפנייה וכו').

## שימוש

- Claude יבחר את הסוכן לבד לפי הבקשה, או בקשו במפורש:
  `השתמש בסוכן meta-ads-manager כדי לנתח את הקובץ ads.csv`
- כדאי לעבוד מתיקייה קבועה לשיווק. הסוכנים שומרים שם, בתת־תיקייה `agent-notes/`, את טבלת המעקב, רשימת "מה נפסל", יומן השינויים במודעות ואת "הקול שלי".

## בדיקה שהסוכנים עובדים

- **תוכן:** "תפרסם את זה עכשיו" ← הוא מבקש אישור. "תכנן לי שבוע" ← הוא פותח בשאלה מה הביא פניות.
- **וידאו:** תנו לו משהו שכבר פסלתם ← הוא מזכיר שזה ברשימה. תנו לו תמלול ← הוא מחזיר טבלה עם זמנים.
- **מודעות:** נתונים של יום אחד ← "לחכות". מודעה שהוציאה פי 2 בלי אף פנייה ← "להשהות".
- **מתחרים:** "תכתוב לי פוסט על זה" ← הוא חוזר לשאול אתכם. הדביקו עמוד ← הוא מפרק אותו בשבע שאלות.

## בלי Claude Code?

באפליקציית Claude הרגילה: צרו פרויקט לכל סוכן, והדביקו את תוכן הקובץ (בלי השורות שבין `---` בראש הקובץ) בשדה ההוראות של הפרויקט.
