# שששש · אפליקציית iOS נייטיב

עטיפת Capacitor שהופכת את אפליקציית הווב שב‑`../baby-sleep` לאפליקציית אייפון אמיתית,
עם אייקון משלה, בלי סרגלי ספארי, ועם הדבר החשוב ביותר: **הצליל ממשיך לנגן כשהמסך נעול**.

## למה בכלל נייטיב

באייפון, אפליקציית ווב שמותקנת למסך הבית מפסיקה להשמיע אודיו ברגע שהמסך ננעל או
שעוברים לאפליקציה אחרת. זו מגבלה ידועה של WebKit, ולאפליקציה שמרדימה תינוק היא קריטית.
הגרסה הנייטיב פותרת אותה דרך שני דברים שהוגדרו כאן:

- `UIBackgroundModes` עם `audio` בקובץ `Info.plist`
- הגדרת `AVAudioSession` לקטגוריית `playback` ב‑`AppDelegate.swift`

בנוסף מתקבלות שליטה ממסך הנעילה, הרשאת מיקרופון אמיתית להקלטה בתוך האפליקציה,
ופתיחה במצב מסך מלא לאורך בלבד.

## מה צריך

- מאק עם Xcode מותקן
- CocoaPods (`sudo gem install cocoapods`)
- חשבון Apple רגיל. חשבון מפתח בתשלום נדרש רק לפרסום בחנות

## בנייה והתקנה

```bash
cd ios-app
npm install
npm run sync          # מעתיק את אפליקציית הווב, מסנכרן ומחיל את ההתאמות
npx cap open ios      # נפתח Xcode
```

אם תיקיית `ios` חסרה, למשל אחרי מחיקה, הריצו במקום זאת `npm run prepare-ios` שיוצר אותה מחדש.

בתוך Xcode:

1. בוחרים את פרויקט **App** ואז לשונית **Signing & Capabilities**.
2. ב‑**Team** בוחרים את חשבון ה‑Apple שלכם. אם אין, מוסיפים אותו דרך
   Xcode → Settings → Accounts.
3. אם Xcode מתלונן שמזהה החבילה תפוס, משנים את **Bundle Identifier** למשהו ייחודי,
   למשל `app.shush.baby.donnel`.
4. מחברים את האייפון בכבל, בוחרים אותו ברשימת היעדים למעלה ולוחצים על כפתור ההרצה.
5. באייפון: הגדרות ← כללי ← ניהול VPN ומכשירים ← נותנים אמון במפתח.

## תוקף ההתקנה

עם חשבון Apple רגיל האפליקציה פועלת שבעה ימים ואז צריך לבנות אותה מחדש מ‑Xcode.
עם חשבון מפתח בתשלום, 99 דולר לשנה, ההתקנה תקפה לשנה ואפשר גם להפיץ דרך TestFlight
או לפרסם בחנות.

## מבנה

```
ios-app/
├── capacitor.config.json   שם האפליקציה, מזהה החבילה והגדרות iOS
├── scripts/copy-web.mjs    מעתיק את ../baby-sleep אל www
├── scripts/patch-ios.mjs   מחיל נגינה ברקע, הרשאת מיקרופון, אייקון ומסך פתיחה
├── assets/                 אייקון 1024 ומסך פתיחה 2732
└── ios/                    פרויקט Xcode
```

אפליקציית הווב היא מקור האמת היחיד. כל שינוי נעשה ב‑`../baby-sleep/index.html`,
ואחריו מריצים `npm run sync`.

## עדכון אחרי שינוי בקוד

```bash
npm run sync
```

הסקריפט `patch-ios.mjs` אידמפוטנטי, אפשר להריץ אותו שוב ושוב בלי לשכפל הגדרות.

## הערה על התלויות

`npm audit` מדווח על חולשות בעץ התלויות של כלי הפיתוח של Capacitor בלבד.
תלויות הריצה, `@capacitor/core` ו‑`@capacitor/ios`, נקיות. הכלים האלה רצים
רק בזמן הבנייה במחשב שלכם ולא נכנסים לאפליקציה.
