# שששש 🌙 — אפליקציה להרדמת תינוק

אפליקציית PWA בעברית שמשמיעה צלילים מרגיעים לתינוקות. אפשר להתקין אותה על הטלפון
כמו אפליקציה רגילה, והיא עובדת גם ללא חיבור לאינטרנט.

## מה יש בפנים

תשעה צלילים, כולם **נוצרים בזמן אמת במכשיר** בעזרת Web Audio API — אין קבצי אודיו,
אין הורדות, אין לולאה שנשמעת חוזרת על עצמה:

| צליל | תיאור |
|---|---|
| 🎙️ ההקלטה שלי | הקלטה של הקול שלכם, בלולאה חלקה. מופיע רק אחרי שמקליטים |
| 🤫 שששש של אמא | שששש נמוך וחם עם נשימה, חספוס ונדבך חזה עמוק |
| 📻 רעש לבן | רעש לבן קלאסי |
| 🌸 רעש ורוד | רעש ורוד, רך יותר מלבן |
| 🔉 רעש עמוק | רעש חום נמוך ועמוק |
| 🌧️ גשם | רעש מסונן עם תנודות עדינות |
| 🌊 גלי ים | גלים עולים ויורדים במחזור של 9 שניות |
| 💗 דופק אמא | צלילי רחם עם פעימות לב בקצב 68 לדקה |
| 🌀 מאוורר | רעש מאוורר עם זמזום מנוע קל |
| 🚗 נסיעה ברכב | רעש נסיעה עמום ומונוטוני |

## הקלטה עצמית

הקול שלכם עדיף על כל סינתזה, כי התינוק כבר מכיר אותו. זה גם מה שעומד מאחורי
Baby Shusher: אבא עייף הקליט את עצמו למכשיר הקלטה קטן, ואותה הקלטה משמשת עד היום.

לוחצים על 🎙️ הקליטו ששש, מקרבים את הפה לטלפון ועושים ששש ברצף 20 עד 30 שניות.
כשהמיקרופון חסום, למשל כשהדף מוצג בתוך מסגרת, האפליקציה מסבירה מה נכשל ומציעה
להעלות קובץ שמע במקום. אפשר להקליט באפליקציית ההקלטות של הטלפון ולהעלות את הקובץ,
והוא עובר בדיוק את אותו עיבוד. קבצים בסטריאו ממוזגים למונו והאורך מוגבל לדקה.
האפליקציה חותכת את הקצוות ומחפפת אותם כך שהלולאה לא נשמעת כמו קפיצה, מנרמלת את
העוצמה ושומרת את ההקלטה ב‑IndexedDB במכשיר בלבד. ההקלטה נעשית עם ביטול מפורש של
הפחתת הרעש של הדפדפן, שאחרת הייתה מוחקת בדיוק צלילים מסוג ששש.

## איך עוצב צליל השששש

הרחם הוא מסנן שמעביר תדרים נמוכים: העובר חשוף בעיקר למתחת ל‑500 הרץ, וכל מה שמעליהם
נחלש ב‑30 עד 50 דציבל. לכן הצליל בנוי סביב 700 עד 900 הרץ ולא סביב התדר הגבוה של
העיצור ש' בדיבור, עם נדבך רעש עמוק מתחתיו, חספוס משלושה קצבי תנודה לא מסונכרנים,
ומעטפת נשימה שמשתנה באורך ובעוצמה בכל מחזור. הרווח בין הנשיפות מתמלא בשאיפה, כך
שאין רגע של שקט מוחלט.

## תכונות

- **כיבוי אוטומטי** — 15 / 30 / 45 דקות, שעה, שעתיים או ללא הגבלה, עם עמעום הדרגתי
  של 45 שניות בסוף כדי שהתינוק לא יתעורר מהפסקה פתאומית.
- **מצב לילה** — מסך שחור לגמרי עם שעון עמום, כדי להניח את הטלפון ליד המיטה.
- **מסך דולק** — מונע כיבוי מסך בזמן ניגון (Wake Lock API).
- **שליטה ממסך הנעילה** — באמצעות Media Session API.
- **שמירת העדפות** — הצליל, העוצמה והטיימר נשמרים למקרה הבא.
- **עובד אופליין** — Service Worker שומר את כל האפליקציה במטמון.

## התקנה בטלפון

1. פותחים את הכתובת בדפדפן הטלפון.
2. **אנדרואיד / כרום** — נלחץ על כפתור ⬇️ התקנה, או תפריט ⋮ ואז "הוספה למסך הבית".
3. **אייפון / ספארי** — כפתור השיתוף ואז "הוספה למסך הבית".

## מבנה הקבצים

```
baby-sleep/
├── index.html            האפליקציה כולה - ממשק ומנוע האודיו
├── manifest.webmanifest  הגדרות ההתקנה בטלפון
├── sw.js                 Service Worker לעבודה ללא אינטרנט
└── icons/                אייקוני האפליקציה
```

## הרצה מקומית

```bash
npx http-server baby-sleep -p 8080
```

## בטיחות

- מומלץ להניח את הטלפון במרחק של כמטר מהמיטה ולא בתוך העריסה.
- ההמלצה המקובלת היא עוצמה של עד כ‑50 דציבל, בערך כמו מקלחת שנשמעת מחדר סמוך.
- כדאי לכבות את הצליל אחרי שהתינוק נרדם — לשם כך קיים הכיבוי האוטומטי.
